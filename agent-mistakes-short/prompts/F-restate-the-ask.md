# F. Restate the ask — before building

Use at the start of a task and whenever the same request returns ("again", "I asked").

```text
Before you build anything, restate my request in one sentence, then quote my exact words next to it. List what you will NOT build or run (extra metrics, expensive runs, variants I did not ask for).
If I ask a question, answer the question first, in the first lines, before reporting other work.
If my words and your restatement differ, stop and ask. When I correct you, say which of my earlier instructions you missed.
Read the rule files I name before the first tool call, and say which ones you read.
```
