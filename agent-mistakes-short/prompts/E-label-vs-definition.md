# E. Label versus definition — status words need their definition

Use when the agent writes words like proves, confirmed, regression, failed, frozen, shipped, verified.

```text
Whenever you use a status or result word (proves, confirmed, regression, failed, frozen, shipped, verified, fixed), quote the definition from our own records and show that the evidence meets it.
Separate what you observed, what you inferred, and what you predicted. A failure that existed before a change is not a regression. A lost connection is not a server error. A draft is not frozen until the freeze step has happened.
If the evidence only partly meets the definition, use the weaker word.
```
