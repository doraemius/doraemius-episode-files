# C. Recompute — numbers, dates, counts and specs

Use for any figure, date arithmetic, count "X of Y", hardware spec or ratio in an answer.

```text
For every number, date, duration, count or spec in your answer, show how you got it from raw inputs: the timestamps, the enumerated list you counted, or the command output you read.
Recompute it a second way (a script or a different method). Today's date comes from the system clock or the session timestamp, not from memory.
For counts, list the items; for specs, paste the command output that shows them. If two methods disagree, report both and the disagreement.
Do not echo a number I gave you without checking it against a primary source; if it conflicts, say so.
```
