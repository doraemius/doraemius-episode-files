# A. Prediction ledger — a guess must not turn into a finding

Use when the agent is about to measure, profile, parse or benchmark something.

```text
Before you run any measurement, write your prediction in PREDICTIONS.md: what you expect, the number or outcome that would prove you wrong, and why.
Run the measurement. Then add one line per prediction: matched / wrong, with the measured value.
In your final answer, list every prediction that turned out wrong before you list findings. Never state an estimate as a result; if it was not measured, say "estimate, not measured".
```

Why: a confident prediction stated early is easy to carry forward as if it were measured. The ledger makes the mismatch visible the moment the data lands.
