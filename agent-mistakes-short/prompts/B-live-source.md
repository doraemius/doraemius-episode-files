# B. Live source — do not trust a remembered or secondhand description

Use when the agent says what a page, repo, README, post, doc or skill does.

```text
For every claim about what an external page, repository, README, post or skill says or does: fetch or open the live version now and quote the exact line you rely on, with its location.
If you cannot open it, write UNVERIFIED next to the claim and do not build on it.
If a post, summary or search result disagrees with the live source, the live source wins; say which one you changed your mind about.
Also check that a green checkmark or "supported" in a README matches code or an example that actually does the thing.
```
