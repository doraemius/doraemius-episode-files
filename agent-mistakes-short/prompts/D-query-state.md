# D. Query the state — do not assume what is running, unused, duplicated or present

Use before deleting, restarting, reporting a duplicate, or saying something is in or out of use.

```text
Before you assert or act on the state of anything (a process, a volume, a file, a listing, a record), run the one command that shows it and paste the relevant output.
For "unused", "orphaned", "duplicate" or "missing": show the evidence that proves it, and count unique items, not rows.
If a tool refuses an action ("in use", "exists", "forbidden"), treat that as information and re-check your claim; do not work around the refusal.
```
